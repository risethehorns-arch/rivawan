# rivawan.com

The website of **Rawan Roshni**: singer, whirler, sound practitioner, facilitator and artivist.

Static, no build step: plain HTML, CSS and JavaScript, served by GitHub Pages at https://rivawan.com.
Edits are made in the project's source folder and synced here by its `deploy.py`.

Designed by [ZYRN](https://zyrn.org).
